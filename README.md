# Политика конфиденциальности CameraDetection

**Дата обновления: 19 октября 2026 года**

Настоящая Политика описывает обработку данных при использовании приложения CameraDetection для Android. Приложение показывает расположение камер на карте и предупреждает пользователя о приближении к ним.

Разработчик находится в Республике Казахстан. По вопросам конфиденциальности можно обратиться по адресу: **muhamedrahman.t@gmail.com**.

## 1. Данные о местоположении

CameraDetection получает доступ к местоположению устройства с разрешения пользователя. Эти данные используются для отображения текущего положения на карте, определения расстояния до камер и предупреждения о приближении к ним.

В текущей версии местоположение используется во время работы с открытым приложением. Функция фоновых предупреждений находится в разработке и не охватывается описанием действующих функций в настоящей редакции Политики.

Данные о местоположении, сохраняемые самим приложением, хранятся локально на устройстве пользователя и не передаются на собственный сервер разработчика. Обработка данных сторонними сервисами описана отдельно ниже.

Пользователь может отказать в доступе к местоположению или отозвать разрешение в настройках Android. В этом случае функции определения положения и предупреждения о приближении к камерам будут недоступны либо ограничены.

## 2. Реклама Google AdMob

В приложении используется Google AdMob для показа рекламы.

Рекламный SDK Google обрабатывает данные, которые могут включать:

- IP-адрес, по которому может определяться приблизительное местоположение;
- рекламный идентификатор Android и другие идентификаторы устройства или приложения;
- сведения о взаимодействии с приложением и рекламой, включая запуски, нажатия и просмотры;
- диагностическую информацию о работе приложения и рекламного SDK.

Эти данные используются для показа рекламы, измерения её эффективности, аналитики и предотвращения мошенничества. Объём обработки зависит от версии SDK, настроек рекламы и доступных пользователю вариантов согласия.

Данные рекламного сервиса могут передаваться Google и обрабатываться за пределами Казахстана. Условия обработки и сроки хранения определяются применимыми правилами Google.

Подробнее:

- [Политика конфиденциальности Google](https://policies.google.com/privacy?hl=ru)
- [Как Google использует информацию из приложений и сайтов партнёров](https://policies.google.com/technologies/partner-sites?hl=ru)

Пользователь может управлять рекламным идентификатором через настройки Android. Доступные действия зависят от версии системы.

## 3. Карты OpenStreetMap

Приложение использует картографические данные OpenStreetMap.

При загрузке карты через интернет сервер, предоставляющий картографические материалы, получает IP-адрес устройства и запросы на отображение определённых участков карты. Такие запросы могут указывать на просматриваемую географическую область.

Если материалы загружаются с серверов OpenStreetMap Foundation, к такой обработке применяется [Политика конфиденциальности OpenStreetMap Foundation](https://osmfoundation.org/wiki/Privacy_Policy).

## 4. Обращения по электронной почте

Если пользователь обращается к разработчику по электронной почте, разработчик получает адрес отправителя и сведения, включённые в сообщение. Они используются для ответа и решения указанного вопроса.

Переписка хранится в течение времени, необходимого для рассмотрения обращения и связанных с ним вопросов. Пользователь может запросить её удаление по контактному адресу, указанному в этой Политике.

## 5. Хранение и удаление данных

Локальные данные приложения хранятся на устройстве до их удаления пользователем. Их можно удалить через функцию очистки данных приложения в настройках Android.

Разработчик не имеет удалённого доступа к локальным данным и не может удалить их с устройства по электронной почте.

Очистка данных приложения не удаляет сведения, ранее полученные сторонними сервисами. Сроки хранения и способы удаления таких сведений определяются правилами соответствующих сервисов.

## 6. Защита данных

Доступ приложения к местоположению контролируется разрешениями Android. Защита локальных данных также зависит от безопасности устройства пользователя.

Передача данных рекламным SDK Google осуществляется с использованием шифрования TLS. При этом ни один способ хранения или передачи информации не обеспечивает абсолютной безопасности.

## 8. Изменения Политики

Политика может обновляться при изменении функций приложения или порядка обработки данных. Актуальная редакция публикуется с указанием даты обновления.

Перед добавлением фонового доступа к местоположению описание соответствующей обработки будет включено в Политику. Необходимые уведомления и запросы разрешений будут представлены в приложении до начала такой обработки.
